## 🚀 ¿Qué es Local Drop?
Es una herramienta web ligera para transferir fotos, videos, audios y documentos desde cualquier celular, tablet u otra computadora directo a tu PC de forma totalmente local, sin subir tus archivos a la nube y con máxima privacidad mediante un token de sesión seguro.

---

## ✨ Características Principales
* 📡 **Sin cables ni internet:** Funciona 100% en tu red local mediante Wi-Fi.
* 📂 **Soporte total:** Fotos, videos, audios y documentos sin restricciones de formato.
* 📱 **Adaptable:** Funciona perfecto en cualquier celular (incluyendo pantallas chicas y formato flip).
* 🔒 **Seguro y efímero:** Token de sesión privado. Al cerrar la sesión, el servidor se apaga y borra todo automáticamente.
* 📦 **Gestión inteligente:** Orden estricto de llegada, filtros rápidos, previsualización de tipos de archivo y descarga individual o masiva en ZIP.

---

## 🛠️ Requisitos Previos
Para que los scripts de inicio funcionen con un solo clic, asegurate de tener instalado en tu computadora:
1. **Node.js** (versión 16 o superior).

---

## 🚀 Cómo usarlo

1. **Cloná o descargá** este repositorio en tu computadora.
2. Ejecutá el archivo correspondiente a tu sistema operativo (`.bat`, `.command` o `.sh`).
3. Se abrirá automáticamente el panel en tu navegador con un código QR.
4. Escaneá el QR con tu celular y empezá a pasar archivos. ¡Listo!
